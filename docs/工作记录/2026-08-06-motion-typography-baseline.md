# Rede 动效与排版基准（2026-08-06 owner 验收通过）

> 来源：owner 判「产品太简陋、像普通工具、没有一体感」→ 做样例 `MotionSampleView`（`-motionSample` 钩子）
> 逐轮对照拍板。本文件是全面改造的**唯一执行基准**，实施时按此对齐，不再逐处重新发明。
> 样例本身是脚手架，改造收官后随之删除。

## 一、连续变形（一体感）

**问题**：全仓 `matchedGeometryEffect` 用量为 **0**。所有转场都是「一个淡出、一个淡入」——
卡片和详情在系统看来是两个无关的东西。这是「普通工具感」的技术根因。

**做法**：同一元素连续变形。点一张卡片，是这张卡片**长大成详情**，不是弹出一个新面板。

**硬约束**：`matchedGeometryEffect` **跨不过 `.sheet` 边界**（sheet 是独立呈现上下文）。
凡要连续变形处，详情必须与列表同层，用 overlay 呈现，自行处理遮罩 / 拖拽关闭 / 无障碍焦点。

**曲线**：`.spring(response: 0.42, dampingFraction: 0.86)`——偏阻尼、无回弹。
极简的动效应当察觉不到，只觉得顺。展开时容器先到位、内容后落下（`.opacity + .offset(y: 10)`），
避免文字跟着缩放变糊。`reduceMotion` 时整条降级为无动画。

**不是每处 sheet 都要改**：设置页那种「确实是另一个地方」的，sheet 才是对的。
要改的是**详情类**——点一个东西看它的细节。

## 二、排版（质感）

### 四档层级，全 App 一以贯之

| 档 | 用途 | 规格 |
|---|---|---|
| 答案 | 今天举多重 | 30pt semibold，`.monospacedDigit()` |
| 执行参数 | 组数 / 休息 / RIR | 25pt medium `.rounded`，等宽 |
| 内容 | 动作名、要点正文 | 16 / 14.5pt regular–medium |
| 结构 | 标签、序号、单位 | 9.5–13pt，压暗至 T4 |

### 三条具体规则

**① 数值簇必须拆分**。`37.5 kg × 6` 整串同字号会退化成一个「标签」。
拆成 `37.5`（大）+ `kg`（小、T4）+ `× 6`（中、T3）。同理 `150s` → `150` + 小号 `s`。
**规则统一**：数值大、单位小、标签最小。凡出现数字的地方都照此办理——
进展页吨位、等级、训练中重量次数、里程碑。

**② 名称让位于数据**。动作名退到 medium + T2，重量用 semibold + T1。
两者同为 semibold 时视线无处落脚，这是「扁平」的主要来源。
**名称是索引，重量才是答案。**

**③ 卡面要有厚度**。纯色填充在深色下像「贴上去的纸」。
用极微弱垂直渐变（`#262218 → #1B1813`）+ 1px 顶缘高光（白 0.075 → 0.012 渐变描边）。
数值全部压到几乎看不见——看得见就俗了。

### 圆角

列表卡 **20**，展开卡 **30**（原 12 / 18）。大圆角是 iOS 26 的语气，
也让卡片读起来更像一块实体而非一个框。

### 两处巧思（owner 确认保留）

- **参数三列化**：`3 组 · 休息 150s · RIR 2` 这串文字拆成三列读数，标签用大字距压到 9.5pt。
  工程感来自结构，不是装饰。
- **要点用工序序号**：`·` 换成 `01 / 02 / 03`（11pt 等宽、透明度 0.75）。
  `·` 只说明「这是一条」，序号说明「这是第几步」——可指认（"第二点没做到"）。

## 三、字体：不换

SF Pro + PingFang SC 保持不变。问题从来不是字形，是**没用足**——
SF Pro 的字重谱系、tabular figures、`.rounded` 设计变体现在用了不到三成。
第三方中文字体授权贵、包体积动辄 5–10MB／字重，且解决不了真正的问题。

## 四、明确不做

- 卡片顶部的 ember 进度线（owner 2026-08-06 判「不用」）
- 动作名配英文小字
- 三列读数之间的竖分隔线
- 任何弹跳、花哨缓动曲线

## 五、改造切片

| 片 | 范围 | 独立验收点 |
|---|---|---|
| S1 | 组件层：`LoadCluster` / `StatStrip` / `CueList` / `RedeCard` 抽成共享件 | 组件单测 + 快照一致 |
| S2 | 今日页（门面，优先级最高） | 列表 + hero 卡 + 详情连续变形 |
| S3 | 训练页（使用频率最高） | 当前动作卡 + 组列表 + 数字滚动 |
| S4 | 进展页 | 数据卡 + 肌群条 → 详情连续变形 |
| S5 | 计划页 + 动作库 | 列表 + 详情 |

零风险纯增益、可与任意片同批做：
`.contentTransition(.numericText())`（重量/次数/吨位变化滚动而非硬切）、
`.symbolEffect`（完成一组的勾选反馈）。
