## zh-Hans（版本更新说明 · 增量）

```
本次更新的重点：今天怎么练，练的时候就能改。

• 训练中直接调整：临时加一个动作、去掉一个还没练的、或者改剩余组数；练完可以把这套改法一键存进这天的计划
• 小肌群动作不再长期卡住：像侧平举这类动作，4 组做成 20/18/16/15 这样的正常递减就会进阶，不用等到每组都做满
• 换动作不再丢记录：练到一半换动作，之前做过的组会如实留在历史里
• 练完升级会告诉你：肌群等级变化、均衡改善都能做成卡片分享；进展页的力量里程碑也能事后分享
• 145 个动作可查循证来源，动作详情里点「查看来源」直达原始研究或权威机构页面
• 减量周不再静默：计划性加量/减量周会在今日页「查看依据」里说清楚
```

## en（What's New · incremental）

```
The focus this time: change today's workout as you go.

• Adjust mid-workout: add an exercise, drop one you haven't started, or change the remaining sets — then save that shape into the day's plan when you finish
• Small-muscle lifts no longer stall: sets like 20/18/16/15 now earn the next load, instead of requiring every set to hit the ceiling
• Swapping an exercise mid-workout keeps the sets you already logged
• Level-ups show up right after you finish; level and balance changes can be shared as a card, and strength milestones are shareable from Progress too
• 145 exercises now link to a real source — tap through from the exercise detail to the study or the certifying body's page
• Planned lighter and higher-volume weeks are now explained in Today's rationale drawer

```

本次更新的重点：训练日怎么排，你说了算。

• 训练日构成自己定：进「编排训练日」换类型、加一天、删一天——想练推拉腿之后再接推拉，直接排出来就行

## en-US (What's New · incremental)

```
The headline this time: your split, your call.

• Build your own split: open Arrange Training Days to swap a day's type, add one, or drop one — run push/pull/legs and keep going into push/pull if that is what you want

• Every edit is undoable, step by step, and nothing takes effect until you tap Apply
```
