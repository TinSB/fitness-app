# Apple Watch 真机验收清单（1.11.0 上架前 · 必做）

> 这一版第一次把手表 app 交到用户手上。下面每条都是**模拟器证明不了**的——不是「再验一遍」，
> 是「只能在真机上验」。左边照着做，右边是应该看到的；对不上就停下来记下来，别放行。
>
> 准备：iPhone 和 Apple Watch 已配对、都装上 TestFlight 版本、手表上 Rede 已从 iPhone 的
> Watch app 安装。找一次真实训练做，别空跑。

---

## 一、通道：模拟器根本不投递的那条

模拟器上 `transferUserInfo` 不投递，所以**「表上记的组到底有没有到手机」只能真机验**。

| 做什么 | 应该看到什么 |
|---|---|
| 手机开始训练 → 手表抬腕 | 手表直接显示当前这一组：动作名、重量、次数、RIR，和手机上是同一个数 |
| **在手表上**点「完成本组」 | 手机那边这一组立刻变成已完成，进度和手表一致 |
| 把 iPhone 熄屏放进包里，手表上连做三组 | 三组都记上；掏出手机时三组都在，没有重复、没有丢 |
| 手表调重量（表冠转两格）后记组 | 手机上这一组的重量是**你在表上改的那个数**，不是原处方的数 |
| 手表上改次数和 RIR 后记组 | 同上，两个数都按表上的落库 |
| 训练中把 iPhone 调飞行模式 → 手表记一组 → 关飞行模式 | 手表上先显示待发数量，恢复连接后自动送达，手机补上这一组 |

## 二、健康 App：写进去 / 不写进去

这条最要紧——**写错了是脏数据，事后清不掉**。

| 做什么 | 应该看到什么 |
|---|---|
| 第一次在手表上打开 Rede | 先弹健康权限门；**不给权限就进不去**（整个手表 app 都需要写入权限） |
| 拒绝权限后再进 | 手表上给一条明确的话说明去哪儿开，不是空白屏或转圈 |
| 正常练完一场（手机上走到小结） | 打开 iPhone 健康 → 体能训练：**有一条**这次的记录，时长和实际差不多 |
| 训练中在手机上点「放弃」 | 健康里**不出现**这场；已有记录数不变 |
| 手机上点「结束训练？」再点「继续训练」 | 健康里最后仍然只有**一条**完整记录，不是被劈成两段 |
| 开始一场，把 iPhone 关机，手表放着不管一小时 | 一小时后手表自己停下；健康里**不写**这场（数据不确定就不写） |

## 三、手感：只有戴在手腕上才知道

| 做什么 | 应该看到什么 |
|---|---|
| 转表冠调重量 | 一格一格有阻尼感，落在真实重量格（2.5 kg 一档），不是连续滑 |
| 点重量 / 次数 / RIR 三个数之间切换 | 点哪个哪个接管表冠，指针滑过去，不需要点两次 |
| 组间休息时抬腕 | 环在走、剩余时间一眼看清；下面一行写着下一组是什么 |
| 休息时点 +30s / 暂停 / 跳过 | 三个都当场生效，手机那边同步跟上 |
| 手放下让屏幕进常亮低亮模式 | 关键数字仍然读得出来，不是全灰成一片 |
| **在健身房实际光照下**看刻线和进度环 | 看得清。看不清就记下来——这是设计取舍，不是 bug，但要知道 |

## 四、边角

| 做什么 | 应该看到什么 |
|---|---|
| 今天不是训练日时打开手表 | 说今天休息，不是显示上一次的动作清单 |
| 今天练完后打开手表 | 说今天练完了、多少组；第一行不再有橙色指示 |
| 热身阶段看手表 | 显示的是**空杆**，不是正式组重量（照着正式组重量练会受伤） |
| 手表上点「跳过本组」 | 要选一个理由；选完手机那边这一组也跳过，理由一致 |
